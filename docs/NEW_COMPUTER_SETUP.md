# 在新電腦上安裝肌少症檢測系統

給要在自己電腦上開啟凱比檢測流程的組員。全部步驟約 20～30 分鐘，大部分時間在下載套件。

## 需要準備

| 項目 | 說明 |
|---|---|
| Windows 10 或 11 電腦 | 一般筆電即可，不需要獨立顯卡；建議 8 GB 以上記憶體 |
| Python 3.12 | 到 <https://www.python.org/downloads/> 下載 **3.12** 版；安裝時勾選「Add python.exe to PATH」 |
| 網路 | 第一次安裝套件時需要；之後檢測時電腦端不需要網路 |
| 凱比、C922 攝影機、兩條 USB 線 | 凱比上已經裝好「肌少症篩檢」App，換電腦不用重裝 |

## 安裝步驟

1. 把整個 `Sarcopenia-Skeletal-Detection` 資料夾複製到電腦上，**路徑不要放在 OneDrive 同步資料夾裡**（例如放在 `C:\Kebbi\`），避免同步時鎖住檔案。
2. 雙擊資料夾裡的 **`install_windows.bat`**，它會：
   - 建立 Python 虛擬環境 `.venv_phase3`；
   - 安裝與開發電腦相同版本的套件（`requirements-lock.txt`）；
   - 檢查 FFmpeg 與 ADB，FFmpeg 找不到時會用 winget 自動安裝；
   - 在桌面建立「肌少症檢測系統」捷徑。
3. 看到「安裝完成」就可以了。若中途失敗，把黑色視窗的訊息截圖給組員。

## 每次使用

1. 凱比開機，用 USB 線接電腦；C922 也接到電腦。
2. 雙擊桌面「**肌少症檢測系統**」：會啟動伺服器、連線凱比並開啟「肌少症篩檢」App，電腦瀏覽器會打開控制台（<http://localhost:8000/control>）。
3. 控制台的「展場預檢」顯示通過後，按「開啟自動偵測」或「啟動一輪檢測」。
4. 結束時雙擊資料夾裡的 `stop_kebbi.bat`。

## 第一次在凱比上使用新電腦

凱比第一次接到這台電腦時，螢幕會跳出「**允許 USB 偵錯嗎？**」，請勾選「一律允許這台電腦」再按「允許」，否則 ADB 連不上凱比。

## 常見問題

| 狀況 | 處理方式 |
|---|---|
| 預檢顯示 C922 畫面未通過 | 確認 C922 有接上，且沒有被 Teams、相機 App 等其他程式佔用 |
| 啟動時說找不到 ADB | 確認資料夾裡有 `tools\platform-tools\adb.exe` |
| 凱比畫面的即時骨架、計次沒有反應 | 凱比頁面的骨架模型目前從網路下載，**凱比需要連 Wi-Fi** |
| 姓名語音備援第一次使用很慢 | 第一次會下載語音辨識模型（需網路），之後就不用 |
| Windows 是英文版，姓名語音備援收不到音 | 設定環境變數 `WEBCAM_MIC_NAME=Microphone (C922 Pro Stream Webcam)` |
